ყოველი ბლოკის ახალი მონეტების (subsidy) 5% ავტომატურად გადაეცემა პროექტის დეველოპერს, განვითარების, სერვერების და მხარდაჭერის დასაფინანსებლად. ეს კონსენსუსის წესია: ბლოკი dev fee-ს გარეშე არავალიდურია. ტრანზაქციების საკომისიო 100%-ით მაინერს რჩება.

მაინინგი / Mining

ნებისმიერი SHA-256 stratum მაინერით.

მიიღე LARI მისამართი

დააინსტალირე საფულე (იხ. ქვემოთ) და გაუშვი cryptolari-cli getnewaddress.

მიუერთდი პულს

username = შენი LARI მისამართი, password = ნებისმიერი.

cgminer -o stratum+tcp://POOL_HOST:3333 -u G…შენი_მისამართი -p x
cpuminer -a sha256d -o stratum+tcp://POOL_HOST:3333 -u G…შენი_მისამართი -p x

# Ubuntu: აწყობა წყაროდან / build from source
git clone https://github.com/tengotengo23/CryptoLari.git && cd CryptoLari
sudo apt-get install build-essential libtool autotools-dev automake pkg-config libssl-dev \
  libevent-dev bsdmainutils libdb++-dev libboost-system-dev libboost-filesystem-dev \
  libboost-chrono-dev libboost-program-options-dev libboost-test-dev libboost-thread-dev
./autogen.sh && ./configure --with-incompatible-bdb && make -j$(nproc)
src/cryptolarid -daemon
