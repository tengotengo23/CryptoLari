# ვორქშოპი „ააწყვე საკუთარი კრიპტოვალუტა“: ინსტრუქტორის გზამკვლევი

4-საათიანი პრაქტიკული ვორქშოპი, სადაც მონაწილეები საკუთარ კომპიუტერზე უშვებენ
CryptoLari-ს კვანძს, უერთდებიან საერთო ქსელს, იღებენ და აგზავნიან მონეტებს,
მაინინგს აკეთებენ და ხედავენ, როგორ იქმნება ახალი კრიპტოვალუტა.

* **ხანგრძლივობა:** 4 საათი (შესვენების ჩათვლით).
* **ჯგუფი:** 8–20 ადამიანი.
* **ფასი (ორიენტირი):** 30–80 ₾ ერთ მონაწილეზე, ან შემოსავლის გაყოფა პარტნიორთან
  (IT აკადემია, უნივერსიტეტი, კოვორკინგი).
* **მონეტები:** მხოლოდ **testnet**, მათ ფასი არ აქვს. ეს სასწავლო ღონისძიებაა და
  არა საინვესტიციო.

მონაწილის ფურცელი (ამობეჭდე ან გაუზიარე): **[LAB.md](LAB.md)**

## 1. მომზადება (2–3 დღით ადრე)

### შენი „ჰოსტ“ კვანძი

ეს კვანძი ყველას საერთო ქსელია. ის შეიძლება იყოს შენი ლეპტოპი (მონაწილეები
ერთსა და იმავე Wi-Fi-ში არიან) ან VPS ([DEPLOY.md](../contrib/cryptolari/deploy/DEPLOY.md);
მაშინ მონაწილეებს ნებისმიერი ინტერნეტიდან შეუძლიათ მიერთება).

```bash
contrib/cryptolari/quickstart.sh --test
contrib/cryptolari/mine.sh --test 4          # 4 = CPU ბირთვების რაოდენობა
```

**მაინინგი ვორქშოპამდე მინიმუმ 1 დღით ადრე დაიწყე.** მოპოვებული მონეტები 100 ბლოკის
(≈3.5 საათის) შემდეგ ხდება ხარჯვადი. ვორქშოპისთვის საჭიროა დაახლოებით 20 მონაწილე ×
5 CLARI = 100 CLARI ხარჯვადი ბალანსი:

```bash
src/cryptolari-cli -testnet getbalance       # ≥ 100 უნდა იყოს
```

### ექსპლორერი და ონკანი (პროექტორზე)

```bash
contrib/cryptolari/explorer/explorer.py --network test --host 0.0.0.0 --port 8080 \
    --faucet-amount 5 --faucet-interval 1 --faucet-daily-limit 200
```

`--host 0.0.0.0`-ით ექსპლორერს მონაწილეებიც გახსნიან: `http://<შენი IP>:8080/`.
შენი IP-ის გასაგებად: `hostname -I`.

> ყველა მონაწილე ერთი Wi-Fi-დან გამოვა, ანუ ერთი IP-დან. ამიტომ `--faucet-interval 1`
> (1 საათი) ნიშნავს, რომ მთელი დარბაზი ონკანს საათში მხოლოდ **ერთხელ** მიიღებს.
> ლაბ 2-ში ამიტომ მონეტებს შენ თვითონ უგზავნი მონაწილეებს (იხ. ქვემოთ), ონკანს კი
> მხოლოდ საჩვენებლად იყენებ.

### Firewall (თუ ჰოსტი შენი ლეპტოპია)

```bash
sudo ufw allow 19955/tcp     # testnet P2P
sudo ufw allow 8080/tcp      # ექსპლორერი
```

### მონაწილეებს ერთი დღით ადრე გაუგზავნე

> გამარჯობა! ხვალ ლეპტოპი მოიტანე, რომელზეც **Ubuntu 22.04/24.04** ან Windows-ზე
> **WSL2 + Ubuntu** აყენია. დაყენების ინსტრუქცია:
> https://learn.microsoft.com/windows/wsl/install
> თუ შეგიძლია, წინასწარ გაუშვი (10–30 წუთი სჭირდება):
> ```
> git clone https://github.com/tengotengo23/CryptoLari.git
> cd CryptoLari && git checkout claude/hopeful-mayer-l05sqi
> contrib/cryptolari/quickstart.sh --test
> ```

### შეამოწმე წინა დღეს
- [ ] ჰოსტ კვანძი მუშაობს და ხარჯვადი ბალანსი ≥ 100 CLARI.
- [ ] მეორე კომპიუტერი ან ტელეფონი ხსნის ექსპლორერს `http://<IP>:8080/`-ზე.
- [ ] მეორე კომპიუტერიდან `--addnode <IP>` ერთდება და ბლოკებს იღებს.
- [ ] დარბაზში არის პროექტორი, დენის წყაროები და სტაბილური Wi-Fi.

## 3. რას ამბობ და აჩვენებ

### შესავალი (0:00–0:30)

**დაწყებისთანავე** სთხოვე ყველას გაუშვას `contrib/cryptolari/quickstart.sh --test`,
რადგან აწყობას დრო სჭირდება. სანამ ეწყობა, ახსენი:

1. **ბლოკჩეინი = საერთო სააღრიცხვო წიგნი**, რომლის ასლი ყველას აქვს. ცენტრალური
   ბანკი ან სერვერი არ არსებობს.
2. **ბლოკი** წიგნის „გვერდია“ და CryptoLari-ში ყოველ ~2 წუთში იწერება.
3. **მაინინგი** რთული ამოცანის ამოხსნაა. ვინც პირველი ამოხსნის, გვერდს წერს და
   10 CLARI-ს იღებს.
4. **საფულე = საიდუმლო გასაღები.** ვისაც გასაღები აქვს, მას ეკუთვნის მონეტები.
5. დღეს **testnet**-ზე ვმუშაობთ: მონეტები ნამდვილია ტექნიკურად, მაგრამ ფასი არ აქვთ.

### ლაბ 1: კვანძი (0:30–1:00)

მონაწილეები უშვებენ: `contrib/cryptolari/quickstart.sh --test --addnode <შენი IP>`
(იხ. LAB.md). **პროექტორზე აჩვენე** ექსპლორერში „კავშირების“ რიცხვის ზრდა.

ახსენი: თითოეული კვანძი დამოუკიდებლად ამოწმებს ყველა ბლოკს. ამიტომ ყალბი ბლოკის
„შემოპარება“ შეუძლებელია.

### ლაბ 2: საფულე და ტრანზაქცია (1:00–1:45)

1. მონაწილეები ჯგუფის ჩატში წერენ თავიანთ მისამართს (`T…`-ით იწყება).
2. **შენ უგზავნი** ყველას 5 CLARI-ს ერთი ბრძანებით:

   ```bash
   src/cryptolari-cli -testnet sendmany "" '{"Tმისამართი1":5, "Tმისამართი2":5}'
   ```

3. ონკანს აჩვენე როგორც მაგალითი: ერთი მონაწილე იღებს მისგან 5 CLARI-ს.
4. მონაწილეები 1 CLARI-ს უგზავნიან მეზობელს და ექსპლორერში ხედავენ, როგორ გადადის
   ტრანზაქცია „რიგიდან“ (mempool) ბლოკში.

ახსენი: საკომისიო, დადასტურებები და ის, რომ გაგზავნილის დაბრუნება შეუძლებელია.

### ლაბ 3: მაინინგი (2:00–2:45)

მონაწილეები უშვებენ `contrib/cryptolari/mine.sh --test 2`-ს. **პროექტორზე აჩვენე**:
ბლოკები ჯერ ძალიან სწრაფად მოდის, მერე სირთულე იზრდება და ბლოკებს შორის დრო ისევ
~2 წუთს უახლოვდება. ეს LWMA ალგორითმია და ყოველ ბლოკზე მუშაობს.

ახსენი: რატომ იყენებს CryptoLari yespower-ს (ჩვეულებრივი CPU და არა ASIC), და რა
არის 51%-იანი შეტევა. მოპოვებული მონეტები „immature“-ა და 100 ბლოკის შემდეგ ხდება
ხარჯვადი: `src/cryptolari-cli -testnet getwalletinfo`.

### ლაბ 4: როგორ იქმნება კრიპტოვალუტა (2:45–3:30)

კოდში ერთად გახსენით `src/chainparams.cpp` და ნახეთ:

* genesis ბლოკი და მისი ტექსტი (`CreateCryptoLariGenesisBlock`);
* ჯილდო და ნახევრება (`nInitialSubsidy`, `nSubsidyHalvingInterval`);
* ბლოკის დრო (`nPowTargetSpacing`);
* მისამართის პრეფიქსები (`base58Prefixes`, `bech32_hrp`).

**ბონუს-დავალება:** თითოეული მოიპოვებს საკუთარ genesis ბლოკს საკუთარი ტექსტით:

```bash
contrib/cryptolari/mine-genesis.py --time 2026-10-01 --message "Giorgi's coin, Tbilisi"
```

ახსენი: ამ ცვლილებით უკვე **სხვა, ახალი** ქსელი იქმნება, რომელიც CryptoLari-ს
ვეღარ დაუკავშირდება.

### უსაფრთხოება და თაღლითობა (3:30–4:00)

* საიდუმლო ფრაზა ან გასაღები **არავის** გაუზიარო, „მხარდაჭერის სამსახურსაც“ კი.
* „გარანტირებული მოგება“, „გაგიორმაგებთ“, „დღეში 5%“ = თაღლითობა.
* ახალი მონეტის ფასი შეიძლება ნულამდე დაეცეს. ყიდვამდე ჰკითხე: ვინ იყიდის ჩემგან
  და რატომ?
* კითხვები და კონტაქტები; სთხოვე შეფასება (Google Forms).
